# Landing Page — Dr. Dante Moreira

## Sobre o projeto

Landing page responsiva desenvolvida como atividade acadêmica da disciplina **Web Standards**, do **Senac EAD**.

O projeto apresenta o site fictício de um psicólogo, com informações sobre sua atuação profissional, serviços oferecidos, abordagem terapêutica e uma seção de contato.

O objetivo foi aplicar conhecimentos de estruturação de páginas web, estilização e desenvolvimento de layouts responsivos.

## Tecnologias utilizadas

- HTML5 — estrutura e organização do conteúdo.
- CSS3 — estilização e apresentação visual.
- Flexbox — organização dos elementos e responsividade.
- JavaScript — interações e validação demonstrativa do formulário.

## Funcionalidades

- Navegação entre as seções da página.
- Layout adaptado para computadores e dispositivos móveis.
- Apresentação dos serviços e da abordagem profissional.
- Formulário de contato demonstrativo com validação.
- Botão de WhatsApp demonstrativo.
